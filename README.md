linkcheck
Программа для проверки ссылок в Markdown и HTML файлах. Она находит все ссылки в указанной папке или файле, проверяет их по сети и показывает список сломанных (битых) ссылок.

Как запустить

Пример команды:

linkcheck -workers 16 -timeout 5s -format json ./docs

Доступные настройки (флаги):
-workers 16 - проверять ссылки параллельно в 16 потоков (чтобы было быстрее).
-timeout 5s - ждать ответа от сайта не дольше 5 секунд.
-format json - вывести результат в формате JSON (если убрать этот флаг, результат выведется как обычный текст).
./docs - путь к папке, в которой нужно проверить файлы.

Коды выхода:
0 - все ссылки доступны, ошибок нет
1 - проверка завершена, но найдены битые ссылки
2 - ошибка запуска (неверные флаги, путь не существует итп)
